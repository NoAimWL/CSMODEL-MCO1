# CSMODEL-MCO1

CSMODEL Major Course Output (AY 2026-27, Term 1): Student Sleep, Screen Time & Academic Performance.

## Structure
- `data/` original dataset (read-only, never edited)
- `notebooks/csmodel_mco.ipynb` main notebook (sections follow the official spec)
- `outputs/` saved figures (empty for now)
- `requirements.txt` dependencies

## Run
```
pip install -r requirements.txt
jupyter notebook notebooks/csmodel_mco.ipynb
```
